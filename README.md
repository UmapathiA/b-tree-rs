# B Tree

A simple implementation of B tree in rust with following features

- Insert a new node
- In order traversal
- Delete a node without rebalancing

## Next

- Child node rebalancing
- Performance optimizations
- Disk based B tree
- Built in benchmark agains other popular tree-structures

## Note:

1. This is just an experiment where I wanted to build a data structure by just reading specifications and with some basic understanding on the similar data structures.
2. Rust's borrowing rules are freely violated by poping and replacing the objects throughout the code.
